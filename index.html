    Reference

    Data Sources, Methodology & Definitions

    Data Sources

    This dashboard draws on three systems: Granicus (planning visits, partner referrals, repeat ACC accounts, booked business), Association Insights (ACC client survey), and Internal Tracking (VA-hosted event surveys).

    Methodology

    The Overview opens with six plain-language questions, each with a short answer built from the same 13 Overview KPIs (the full 13-card grid is one click away under "Show full metrics"). The Overview's From/To date picker drives both the answers and all 13 cards. Each card compares the picked date range with the same calendar dates one year earlier ("YoY"). By default the range runs from January 1 of the current year through the end of the latest month with populated Planning Visits data. Source sheets update on different lags, so if a sheet's data ends before the To date, that card is cut off at the end of the sheet's latest populated month and the prior-year window is cut off at the same point, keeping the comparison like-for-like. The Planning Visits sheet is monthly, so its cards include every month the picked range touches.

    Each section page has its own filters (matching the production dashboard) and recomputes every card, chart, and table live from the raw rows in data.json using the production app.js formulas. Section KPI deltas use the same year-to-date methodology: the selected (or latest) year is compared with the prior year over an identical January-through-cutoff window. Client Survey "Ratings by Year" uses full-year averages. The Hosted Events & Booked Business cross-reference is pinned to 2025 until 2026 Event IDs are reconciled between the two sheets.

    Definitions

    Partners Visited
    A partner property visited in person during a planning visit.
    Partner Referrals
    A non-physical referral, such as email, phone, or shared contact info (as distinct from Partners Visited, which is an in-person visit).
    Clients Serviced During Planning Visits
    Counts the clients who attend each planning visit (row count of the Repeating ACC Clients Services sheet).
    Repeat Account
    A distinct account (Account ID) with at least one booking whose "Repeat Business" value on the sheet is Yes.
    Avg. Conversion Window
    Average days from lead created to event start (shown in months once above 90 days).
    Sources: Granicus, Association Insights, and Internal Tracking.
